# TRY — real-world activities

Families: Move & Play, Create & Make, Nature & Notice, Think & Discover, Help & Everyday Life, Family & Connect, Calm & Mindful Moments. These are internal categories, not new pillars.

Follow content/schemas/activity.schema.json and examples/try-activity-example/activity.json. Required: age band, goal, materials, supervision, hazards/safety, steps, duration, accessibility, alternatives, provenance and review state.

Flow: preview → parent safety note → concise instructions → step away → optional return. TV need not remain on. On-TV instructions count as screen use; off-TV activity does not. Explicitly consider choking, heat, sharp tools, allergens, water, traffic and climbing. Human review required.
