# PLAY — game contributions

Contribute proposals, data-driven definitions for supported mechanics, reviewed implementations or reusable mechanics. Follow content/schemas/game.schema.json and examples/game-example/game.json.

Required: unique ID, age band, summary, learning goals, mechanics, remote mapping, duration, offline behaviour, accessibility, provenance and review state. Only UP/DOWN/LEFT/RIGHT/OK/BACK; define focus/back behaviour, rules, feedback, retry and end state. No manipulative rewards or feature-level global timers. Arbitrary dynamic game-code loading is out of scope.
