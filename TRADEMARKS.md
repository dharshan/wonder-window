# Name and mascot policy

"Wonder Window" and its default mascot "Pip" identify this project's child-safety promises: no ads, no tracking, no streaks or earned screen time, parent-approved content and one shared screen-time limit.

- You may use the name to refer to the project, and you may ship unmodified builds under it.
- If a fork changes any child-safety, privacy or screen-time rule (AGENTS.md, docs/CHILD_SAFETY.md, docs/SESSION_TIME_POLICY.md), it must use a different name and mascot.
- Families can rename the app and mascot for their own TV in `family.properties`; that is a personal setting, not a fork.

This policy covers names and mascot art only. Code is MIT; documentation and original content are CC BY 4.0 (see LICENSE and LICENSE-DOCS).
