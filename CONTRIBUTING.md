# Contributing

Read AGENTS.md and the relevant product/safety docs before contributing.

Areas: [PLAY](features/play/README.md), [TRY](features/try/README.md), [WATCH](features/watch/README.md), [Design](design/README.md), [Core](core/README.md).

Workflow: open/find an issue; fork and branch; follow the matching template/schema; add tests and provenance; run `python3 -m pip install jsonschema && python3 tools/validate_content.py`; submit a focused PR with age band, safety, accessibility, licence and device-test evidence. Passing CI is not child-safety approval.

Do not submit copyrighted content/assets without redistribution rights. Never commit secrets or children's personal data. Child-facing content requires human review.
