# WW-009 · Shadow Match (our id `ww009`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: G. Spatial Awareness & Visual Intelligence / Visual Matching / Silhouettes · Variant: `pick`

**1. Identity.** Original title "Shadow Match", catalogue id WW-009. Source record unchanged in master.json.

**2. Age band.** Record 4-6 / 4-7; fits him; L3 rotation is a stretch.

**3. Objective (observable).** He selects the dark silhouette that has the same outline as a coloured object, from 3 silhouettes.

**4. What he practises.** Using outline and parts (trunk, tail, wheels) rather than colour to match shapes; mental rotation of small angles at L3. (Source objective: "Match an object to its correct silhouette".)

**5. Originality and dedup.** No existing game; Same or Different (WW-014) judges pairs, while this one matches shape outlines. Separate. Decision: **own game**.

**6. Core loop.** Object card on the left; 3 shadow cards (engine renders choices dark, 'silhouette': true). Correct shadow merges with the object.
Example rounds:
- L1 `ww009-1-01`: "Find its shadow!", board 🐘; choices 🐘 🐟 ⭐; answer 🐘. Spoken: "Look at the picture. Which dark shadow is the same shape?"
- L2 `ww009-2-01`: "Find its shadow!", board 🐕; choices 🐕 🐈 🐄; answer 🐕. Spoken: "Look at the picture. Which dark shadow is the same shape?"
- L3 `ww009-3-01`: "Find its shadow!", board 🐘; choices 🦛 🦏 🐘; answer 🐘. Spoken: "Look at the picture. Which dark shadow is the same shape?"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first session. Narration only on 🔊: "Cherry has a torch! It makes shadows on the wall. Find the shadow that matches the picture." Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** Row of 3 shadows, LEFT/RIGHT, OK, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 very different shapes, L2 same-category look-alikes, L3 the correct shadow is rotated 45-90° (choice_rotate) and distractors are tilted by 15°. Levels: L1 Very different shapes 🌑, L2 Look-alike shapes 🌓, L3 Turned shadows 🔄.

**10. Hint / retry / recovery.** Miss: the object's outline is traced in yellow for 1 s. 🔊 always replays the line. After the second miss the answer is shown and he presses it ("You kept going!"). Nothing is lost.

**11. Success, session end, early exit.** 5 rounds. Each set is 5 rounds. BACK cancels any local action first (palette, peek), then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Soft merge or glow animation on correct match. Neutral return on incorrect."). Correct: one of 6 `cheers`, the scene fills (🔦), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 15-20 s per round; about 1.5-2 min. Target 1.5-4 min (record estimate 1-2.5 min).

**14. Assets / audio / content.** Silhouette rendering = emoji drawn with a solid #1F2547 colour filter (PorterDuff SRC_IN); a torch beam overlay. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww009`.

**15. Accessibility.** Silhouettes are on a pale wall (high contrast). No colour cue needed. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, allow rotation (L3) on or off, reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Silhouette filter renders every emoji used (no tofu); choice_rotate length matches choices; rotation never hides the answer's identity. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Clements, D. H. & Sarama, J. (2014), Learning and Teaching Early Math: The Learning Trajectories Approach (Routledge): shape recognition and composition trajectories. Limitation: background only. We claim only practice of the skill inside the activity.
