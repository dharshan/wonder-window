# WW-100 · Shape Hunt (our id `ww100`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: C. Mathematics & Numerical Thinking / Shapes & Geometry · Variant: `pick`

**1. Identity.** Original title "Shape Hunt", catalogue id WW-100. Source record unchanged in master.json.

**2. Age band.** Record 4-6; fits him.

**3. Objective (observable).** He finds a picture that has the target shape: the same shape in a different colour (L1), then a real object shaped like it (L2), then two of four objects (L3).

**4. What he practises.** Recognising circles, triangles, squares (plus heart, star, diamond at L1) in pictures and everyday things; naming the shape by its corners. (Source objective: "Find all examples of a target shape in a scene".)

**5. Originality and dedup.** Shape Count (ww054) counts one shape among many; here he finds the one that matches or the real object shaped like it. Different action (find, not count). Decision: **own game**. The source says 'find all examples'; a multi-select hunt would need a new variant (`find_all`: several correct taps in one round). Here L3 uses `also_ok` (one of two right answers) and says 'there is more than one'.

**6. Core loop.** A target shape sits on the board. He picks the matching shape or object. L3 invites a second find: the round finishes on the first right pick.
Example rounds:
- L1 `ww100-1-01`: "Find the same shape!", board ⚫, choices 🔲 🔵 🌟, answer 🔵. Spoken: "Look at the shape. Which one is also a circle?"
- L2 `ww100-2-01`: "Find the same shape!", board ⭕, choices 🐟 ⏰ 🎲, answer ⏰. Spoken: "Look at a circle. Which one is shaped like a circle?"
- L3 `ww100-3-01`: "Find something with this shape!", board ⭕, choices ✏️ 🥥 🌕 🍕, answer 🌕 (also 🥥). Spoken: "Look at a circle. Find something shaped like a circle. There is more than one!"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first session. Narration only on 🔊: "Shapes hide everywhere around us. Let's go on a shape hunt with Cherry!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the choices, OK confirms, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 three shape pictures (find another circle, triangle...). L2 three objects (a football is a circle). L3 four objects, two of them have the shape. Levels: L1 Same shape 🔴; L2 Shapes around us ⚽; L3 Find more than one 🔍.

**10. Hint / retry / recovery.** After 1 miss the choice fades and the `hint` is shown (voice only on 🔊). After 2 misses the answer is shown and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** Session = 5 rounds, then the end_lines and the Play again / Back to games buttons. Early exit any time via BACK: it cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Soft positive confirmation. Errors receive neutral feedback and the chance to try again. No negative sounds or messages."). Correct: one of 6 `cheers`, the scene fills (🔷), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 20-35 s per round; 5 rounds take about 2-3 min. Target 1.5-4 min (record estimate 1.5-4 min).

**14. Assets / audio / content.** Shape emoji and everyday-object emoji (football, tent, dice...). All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww100` (30 rounds, 3 levels).

**15. Accessibility.** Meaning is carried by the pictures, not by colour alone; labels are screen text for the parent only.  Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, starting level, reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Each round has one defensible answer (plus `also_ok` where listed); choices distinct; labels match choices; `fade` is never a right answer. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Background: recognising basic 2D shapes is a core early-years geometry goal (NCF-FS, NCERT 2022). Limitation: framework, not effect evidence. We claim only practice of the skill inside the activity.
