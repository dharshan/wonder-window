# WW-017 · Story Steps (our id `ww017`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: D. Language & Literacy / Story Sequencing · Variant: `order`

**1. Identity.** Original title "Story Steps", catalogue id WW-017. Source record unchanged in master.json.

**2. Age band.** Record 5-7; fits him.

**3. Objective (observable).** He puts 3-4 mixed-up story pictures into the order they happen.

**4. What he practises.** Narrative sequencing (first, then, last), retelling with labels; life cycles and daily routines. (Source objective: "Put simple story events into the correct chronological order".)

**5. Originality and dedup.** What Comes Next? picks one ending; this builds the whole order (order variant). Different action. Separate. Decision: **own game**.

**6. Core loop.** Shuffled picture cards below, a storybook strip with numbered slots above. Correct next card flies to the next slot; at the end the story plays with labels.
Example rounds:
- L1 `ww017-1-01`: "Put the story in order!", order 🥚 🐣 🐔. Spoken: "A story about a hen. Which picture comes first?"
- L2 `ww017-2-01`: "Put the story in order!", order 🥚 🐣 🐥 🐔. Spoken: "A story about how a hen grows. Which picture comes first?"
- L3 `ww017-3-01`: "Put the story in order!", order ❄️ ⛄ ☀️ 💧. Spoken: "A story about a snowman. Which picture comes first?"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first session. Narration only on 🔊: "Oh no, my storybook pages are mixed up! Help me put them in order." Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the remaining cards, OK sends, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 3 pictures, L2 4 pictures, L3 4 pictures needing more thought (blow the candles, then eat the cake). Levels: L1 Three pictures 📗, L2 Four pictures 📘, L3 Think it through 📙.

**10. Hint / retry / recovery.** After 2 wrong picks: the first missing step's card bounces; the voice gives the story start. 🔊 always replays the line. After the second miss the answer is shown and he presses it ("You kept going!"). Nothing is lost.

**11. Success, session end, early exit.** 5 stories per set. Each set is 5 rounds. BACK cancels any local action first (palette, peek), then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Story plays through gently on success. Soft guidance on incorrect order."). Correct: one of 6 `cheers`, the scene fills (📖), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 30-45 s per round; about 3-4 min (the parent can set 4 rounds). Target 1.5-4 min (record estimate 2-4 min).

**14. Assets / audio / content.** Story cards with labels (screen text), page-turn sound. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww017`.

**15. Accessibility.** Labels optional; the pictures carry meaning. Large cards. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Each story has one defensible order; items distinct; labels match items. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Story sequencing and retelling: NCF-FS (NCERT, 2022) language goals. Limitation: framework, not effect evidence. We claim only practice of the skill inside the activity.
