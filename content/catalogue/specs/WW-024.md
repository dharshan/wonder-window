# WW-024 · Spell the Word (our id `ww024`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: D. Language & Literacy / Word Building / Phonics · Variant: `order`

**1. Identity.** Original title "Word Builder", catalogue id WW-024. Source record unchanged in master.json. Decision: **own game (named Spell the Word to avoid the core `word` game name)**.

**2. Age band.** Record says 6-7 primary / 5-7, 6-8. He is 5½: fits from L1.

**3. Objective (observable).** He presses the letters of a pictured word in order to build it (3 to 5 distinct letters). (Source objective: "Build simple CVC or familiar words by selecting letters in order".)

**4. What he practises.** Segmenting a word into sounds, mapping sounds to letters, left-to-right order.

**5. Originality and dedup.** Core Word Builder picks one letter from three; this builds a whole word letter by letter (order variant). Different action. Letters in each word are all different so the order engine can check it. Decision: **own game**.

**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww024-1-01`: "Build the word 🐱!" Spoken: "Build the word for the cat. Say it slowly, then find each sound in order!"
- L3 `ww024-3-01`: "Build the word 🐴!" Spoken: "Build the word for the horse. Say it slowly, then find each sound in order!"

**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first set. Narration only on 🔊: "Oh no, my word blocks fell down! Help me put the sounds back in order." Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the remaining cards, OK sends the card to the next slot, UP for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 three-letter words, L2 four, L3 five (stretch, above his age band). In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Three sounds 3️⃣; L2 Four sounds 4️⃣; L3 Five sounds 5️⃣.

**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Word gently celebrates or the picture animates on success. Soft letter return on error."

**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, the buddy (Pip) the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b2.json` → `ww024`.

**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Phonemic segmentation and blending: NCERT NCF-FS (2022) early literacy. Limitation: framework only. We claim only practice of the skill inside the activity.
