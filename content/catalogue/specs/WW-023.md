# WW-023 · Add the Animals (mode in core `number`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: C. Mathematics & Numerical Thinking / Simple Addition · Variant: `pick`

**1. Identity.** Original title "Add the Animals", catalogue id WW-023. Source record unchanged in master.json. Decision: **merged_into number (mode `number-add-animals`)**.

**2. Age band.** Record says 6-7 primary / 5-7, 6-8. He is 5½: fits from L1.

**3. Objective (observable).** He counts two groups of animals together and presses the total (sums to 10). (Source objective: "Solve simple concrete addition problems (sums to 10)".)

**4. What he practises.** Counting on, combining groups, number words up to ten.

**5. Originality and dedup.** Number Explorer already has 'How many altogether?' rounds (L3-L5). Same objective and same action (press the total). Decision: **merged_into number**; the animal theme becomes a mode with 30 rounds.

**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww023-1-01`: "How many altogether?" Spoken: "One dogs, and one more. How many dogs altogether?"
- L3 `ww023-3-01`: "How many altogether?" Spoken: "Five monkeys, and three more. How many monkeys altogether?"

**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first set. Narration only on 🔊: "(shares the voice of core `number`; round lines only)" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT (and UP/DOWN on the 2x2 grid) over the choices, OK answers, UP on the speaker for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 sums to 5 (pictures), L2 sums 6-7 (pictures), L3 sums 8-10 (numeral plus one picture, because the board holds at most 8 items). In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Up to five 5️⃣; L2 Up to seven 7️⃣; L3 Up to ten 🔟.

**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Animals gently group together and celebrate on correct answer."

**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, the buddy (Pip) the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b2.json` → merged mode `number-add-animals`.

**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Early addition by counting all / counting on: NCERT NCF-FS (2022) numeracy goals. Limitation: framework only. We claim only practice of the skill inside the activity.
