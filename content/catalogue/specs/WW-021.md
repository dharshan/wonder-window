# WW-021 · Odd One Out (mode in core `pattern`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: A. Cognitive & Logical Thinking / Classification / Odd One Out · Variant: `pick`

**1. Identity.** Original title "Odd One Out", catalogue id WW-021. Source record unchanged in master.json. Decision: **merged_into pattern (mode `pattern-odd-one-out`)**.

**2. Age band.** Record says 5-6 primary / 4-6, 5-7. He is 5½: fits from L1.

**3. Objective (observable).** He looks at four pictures and presses the one that does not belong with the other three. (Source objective: "Identify the item that does not belong in a group based on a shared attribute".)

**4. What he practises.** Classification by a shared property (kind, use, place, colour); explaining why a thing is different.

**5. Originality and dedup.** Pattern Detective already asks 'Which one does not belong?' (L4). Same objective and same action (pick the odd one of four), so this is a dedicated mode of `pattern`, not a new game. Decision: **merged_into pattern**; extra content = 30 odd-one-out rounds.

**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww021-1-01`: "Which one does not belong?" Spoken: "Apple, banana, grapes, car. Three are fruits. Which one does not belong?"
- L3 `ww021-3-01`: "Which one does not belong?" Spoken: "Football, orange, tennis ball, book. Three are round things. Which one does not belong?"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first set. Narration only on 🔊: "(shares the voice of core `pattern`; round lines only)" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT (and UP/DOWN on the 2x2 grid) over the choices, OK answers, UP on the speaker for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 an obvious different kind (car among fruit), L2 a closer category (elephant among sea animals), L3 reason by property (round, wheels, light, cold). In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Easy odd one 🍎; L2 Look closer 🔍; L3 Think about it 💭.

**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Soft highlight of the common rule on success. Gentle neutral feedback on error."

**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, Cherry the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b2.json` → merged mode `pattern-odd-one-out`.

**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Classification goals: NCERT NCF-FS (2022). Limitation: framework, not effect evidence. We claim only practice of the skill inside the activity.
