# WW-015 · Memory Tray (our id `ww015`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: B. Memory & Concentration / Visual Memory / Change Detection · Variant: `pick`

**1. Identity.** Original title "Memory Tray", catalogue id WW-015. Source record unchanged in master.json.

**2. Age band.** Record 5-7 / 5-8; fits him.

**3. Objective (observable).** After studying a tray of 3-5 objects, he identifies what is missing (L1) or which object changed (L2-L3).

**4. What he practises.** Looking carefully, holding a small set in mind, and noticing a change (including small colour or detail changes at L3). (Source objective: "Notice what has changed in a small set of objects".)

**5. Originality and dedup.** Shape Echo reproduces order; this detects change in a set (peek variant). Different action. Separate. Decision: **own game**.

**6. Core loop.** The peek_board is shown for peek_ms with a 'look' eye icon; then a cloth sweeps across and the changed board appears; choices appear.
Example rounds:
- L1 `ww015-1-01`: "What is missing?", board 🍎 ❓ 🥭 (peek 🍎 🍌 🥭); choices 🌳 🍌 🐘; answer 🍌. Spoken: "Look at the tray. Remember everything! Now one thing is gone. What is missing?"
- L2 `ww015-2-01`: "Which one is new?", board 🍎 🍌 🍍 🍇 (peek 🍎 🍌 🥭 🍇); choices 🍎 🍇 🍌 🍍; answer 🍍. Spoken: "Look at the tray. Remember everything! Now one thing has changed. Which one is new?"
- L3 `ww015-3-01`: "Which one is new?", board 🍐 🍌 🥭 🍇 🍊 (peek 🍎 🍌 🥭 🍇 🍊); choices 🍇 🍌 🍐 🥭; answer 🍐. Spoken: "Look at the tray. Remember everything! Now one thing has changed. Which one is new?"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first session. Narration only on 🔊: "Ajji has a tray of things. Look carefully and remember. Then find what changed!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** During the peek, no choices are focusable (BACK pauses; OK skips the remaining peek time if he is ready). Then a row of 3-4 choices, LEFT/RIGHT, OK; UP = 'look again' (replays the peek, the same as the hint). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 3 items, missing one (3 s); L2 4-5 items, one replaced (3.5 s); L3 subtle swaps of colour or detail (4 s). The parent can lengthen the peek. Levels: L1 What's missing? ❓, L2 What's new? ✨, L3 Tiny changes 🔬.

**10. Hint / retry / recovery.** Miss: the original tray is shown again (look again), then he retries. 🔊 always replays the line. After the second miss the answer is shown and he presses it ("You kept going!"). Nothing is lost.

**11. Success, session end, early exit.** 5 trays. Each set is 5 rounds. BACK cancels any local action first (palette, peek), then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Soft reveal of the difference. Option to see original again."). Correct: one of 6 `cheers`, the scene fills (🍽️), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 20-30 s per round; about 2-2.5 min. Target 1.5-4 min (record estimate 1.5-3.5 min).

**14. Assets / audio / content.** Tray card, cloth sweep animation, eye icon. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww015`.

**15. Accessibility.** Peek time adjustable (+50% / +100%); not a race, since OK ends the peek early only when he chooses. Items differ by shape. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, number of objects, peek length, reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Exactly one position differs between peek_board and board; the answer is the changed or missing item; the peek can be replayed unlimited times. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Visual short-term memory background: Gathercole & Alloway (2008). Limitation: no transfer claim (Melby-Lervåg & Hulme, 2013). We claim only practice of the skill inside the activity.
