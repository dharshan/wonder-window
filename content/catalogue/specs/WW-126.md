# WW-126 · Clean Up (mode `sort-clean-up` in core game `sort`)
Status: **merged_into sort** · Category: J. Real-World Knowledge & Life Skills / Environmental Care

**Objective (source).** Sort items into recycling, compost, or general waste

**Decision.** merged_into `sort` (Sorting Adventure, core game), as the new mode **Clean Up** (`sort-clean-up`, 30 rounds, 3 levels, 3 rounds per session, `place` variant).

**Reason.** Same objective (put things into the right waste bins) and the same placing action as Sorting Adventure, which already has a 'Wet waste or dry waste?' set (banana peel, newspaper, tin can) and the modes sort-category-baskets and sort-healthy-plate. What the source adds is three bins (compost, recycle, rubbish bin) and more items per round, which is content for the `place` variant, not a new game. Bangalore wet waste = compost and dry waste = recycle, so the two sets agree.

**How it plays.** Several things appear; he moves each to the right bin and presses OK; a wrong bin bounces it back kindly. Example rounds:
- L1 `ww126-1-01`: "Which bin does it go in?", bins 🌱 compost ♻️ recycle, items 🍌 🧴 🍉 📒, answers [0, 1, 0, 1]. Spoken: "Each thing goes in a bin. Where does it go? Move and press OK!"
- L2 `ww126-2-01`: "Which bin does it go in?", bins 🌱 compost ♻️ recycle 🗑️ rubbish bin, items 📄 📦 🍂 🍽️ 🎈 🥭, answers [1, 1, 0, 2, 2, 0]. Spoken: "Compost, recycle, or rubbish bin? Put each thing in the right bin. Move and press OK!"
- L3 `ww126-3-01`: "Which bin does it go in?", bins 🌱 compost ♻️ recycle 🗑️ rubbish bin, items 🥫 🎈 🧸 🥭 🍉 🌽 📄 📰, answers [1, 2, 2, 0, 0, 0, 1, 1]. Spoken: "Plants go to compost. Paper, tins and bottles are recycled. The rest is rubbish. Move and press OK!"
L1 two bins and four things; L2 three bins and six things; L3 three bins and eight things. Hint: 'Think: does it come from a plant, can it be made again, or is it just rubbish?' (voice only on 🔊). Alias WW-126 → sort recorded.

**Evidence and limits.** Waste sorting is an early environmental-care habit (NCF-FS, NCERT 2022); framework, not effect evidence.
