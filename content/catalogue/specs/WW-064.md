# WW-064 · Colour Mix (our id `ww064`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: E. Creativity & Imagination / Colour Combinations · Variant: `pick`

**1. Identity.** Original title "Colour Mix", catalogue id WW-064. Source record unchanged in master.json. Decision: **own game (adapted to pick)**.
**2. Age band.** Record says 5-7 primary / 5-7. He is 5½: fits from L1.
**3. Objective (observable).** He decides which colour two paints make (L1), which two paints make a colour (L2), or which paint is missing (L3). (Source objective: "Mix two colours to create a target colour".)
**4. What he practises.** Colour mixing facts (blue + yellow, red + yellow, red + blue, red + white); naming colours; reversing a rule.
**5. Originality and dedup.** Colour Nest (WW-001) and Attribute Switch sort things by colour; nothing teaches mixing. The record is a 'create' game (he mixes with a palette); the engine has no mixing canvas, so the game asks the same facts as a choice. Free mixing is not proposed; the facts are the learning. Decision: **own game**.
**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww064-1-01`: "What colour do they make?" Spoken: "Blue and yellow mix together. What new colour do they make? Purple, orange, or green?"
- L3 `ww064-3-01`: "Which colour is missing?" Spoken: "Blue and something make green. What is the missing colour? Yellow, red, or purple?"
**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first set. Narration only on 🔊: "Two paints mix together to make a new colour. Can you find it?" Prompt text 8 words or fewer (he can't read; it is for the parent).
**8. Remote mapping.** LEFT/RIGHT (and UP/DOWN on the 2x2 grid) over the choices, OK answers, UP on the speaker for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.
**9. Difficulty.** L1 two paints make a colour (hearts show the colours); L2 reverse, pick the pair; L3 one paint is hidden (❓). Pink comes from red and white. In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Mix two paints 🎨; L2 Which two make it? 🖌️; L3 Missing paint ❓.
**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.
**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.
**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Gentle positive visual confirmation on success. Neutral, non-punitive feedback on errors with option to try again. No timers or pressure."
**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.
**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, Cherry the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b4.json` → `ww064`.
**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).
**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.
**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.
**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.
**19. Evidence and limits.** Colour mixing: NCERT NCF-FS (2022) creative arts goals. Limitation: framework only. Accessibility note: meaning rests on colour, so every choice has a spoken colour name and a parent label. We claim only practice of the skill inside the activity.
