# WW-014 · Same or Different (our id `ww014`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: A. Cognitive & Logical Thinking / Matching & Comparison · Variant: `pick`

**1. Identity.** Original title "Same or Different", catalogue id WW-014, legacy alias A010. Source record unchanged in master.json.

**2. Age band.** Record 3-5 / 3-6; L1 is easy for him, L2-L3 fit.

**3. Objective (observable).** He judges whether two pictures are the same or different (whole object, then by colour, shape or size, then subtle details).

**4. What he practises.** Careful comparison; attending to one attribute while ignoring others (same colour, different object). (Source objective: "Decide whether two objects are the same or different on a given attribute".)

**5. Originality and dedup.** No existing game judges same/different. Legacy A010 has the same title and only a concept, so it is kept as an alias. Decision: **own game**.

**6. Core loop.** Two big pictures, two answer buttons: 🧦🧦 'same' and 🧦👟 'different' (always in that order).
Example rounds:
- L1 `ww014-1-01`: "Same or different?", board 🍎 🍎; choices 🧦🧦 🧦👟; answer 🧦🧦. Spoken: "Look at these two. Are they the same, or different?"
- L2 `ww014-2-01`: "Same or different?", board 🍎 🚒; choices 🧦🧦 🧦👟; answer 🧦🧦. Spoken: "Look at the colours. Are they the same colour, or different?"
- L3 `ww014-3-01`: "Same or different?", board 😀 😃; choices 🧦🧦 🧦👟; answer 🧦👟. Spoken: "Look at these two. Are they the same, or different?"

**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first session. Narration only on 🔊: "Look at two things. Are they the same, or different? Look carefully!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT between the 2 buttons, OK; UP 🔊; BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 whole objects, L2 one named attribute (colour or shape), L3 subtle (face details, clock hands, size). Levels: L1 Easy pairs 🧦, L2 Same colour, same shape 🎨, L3 Tiny differences 🔬.

**10. Hint / retry / recovery.** Miss: the differing part (diff_hint) is softly circled, e.g. the eyes or the colour. 🔊 always replays the line. After the second miss the answer is shown and he presses it ("You kept going!"). Nothing is lost.

**11. Success, session end, early exit.** 5 rounds. Each set is 5 rounds. BACK cancels any local action first (palette, peek), then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Gentle confirmation. On error, soft highlight of the differing attribute."). Correct: one of 6 `cheers`, the scene fills (🔍), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 10-20 s per round; about 1.5 min. Parent can set 8 rounds. Target 1.5-4 min (record estimate 1-2.5 min).

**14. Assets / audio / content.** Pair cards, sock icons, a circling highlight. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww014`.

**15. Accessibility.** Answer buttons differ by picture and label, not colour. L2 colour rounds always pair with shape-identical or clearly different objects. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, attribute focus (colour/shape), reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Fixed button order; diff_hint present on every 'different' round; same rounds use identical emoji. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Comparison and classification are foundational in Clements & Sarama (2014). Limitation: background only. We claim only practice of the skill inside the activity.
