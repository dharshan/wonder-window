# WW-027 · Moon Maze (our id `ww027`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: G. Spatial Awareness & Visual Intelligence / Mazes · Variant: `grid_path`

**1. Identity.** Original title "Moon Maze", catalogue id WW-027. Batch b13 (worksheet-inspired play, 24 Nov 2026). Skill borrowed from worksheet sites; all text, pictures and layouts are our own.

**2. Age band.** Kindergarten (UKG); fits him.

**3. Objective (observable).** He moves the astronaut, rocket or saucer with the arrows from the start to the goal (and, in L3, via the star).

**4. What he practises.** Path planning, direction words and turning back from a dead end. (Source skill: "Mazes; following a path".)

**5. Originality and dedup.** Little Navigator (core `nav`) is a city maze. This is a moon-theme set with 3x3 to 6x6 grids and the same action; kept as a themed own game because the catalogue id was deferred. Decision: own game on the existing grid_path engine.

**6. Core loop.** A tilted tile map on the moon. Arrows move one tile; walls bump softly; OK replays the voice line.
Example round: `ww027-1-01` (3x3 grid, no star). Spoken: "Help the rocket get to the moon! Use the arrow buttons."

**7. Child-facing instruction.** Visual demo by {buddy} (Astro) in round 1 of the first session. Narration only on 🔊: "Let's find the way on the moon! Use the arrow buttons to move. Take your time." Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the choices (or the object and its baskets), OK confirms, UP 🔊, BACK pause. Maze: arrows move one tile, OK replays the line. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Exactly one element is focused.

**9. Difficulty.** L1 3x3 and 4x4 (5 each). L2 5x5, every maze has a dead end. L3 6x6 with a star to collect first (`need_star`). 10 mazes per level; the validator solves every one. Levels: L1 Small mazes 🌑; L2 A dead end 🛸; L3 Collect the star ⭐.

**10. Hint / retry / recovery.** After 1 miss the choice fades and the `hint` is shown (voice only on 🔊). After 2 misses the answer is shown and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost. Maze: bumps never cost anything; the hint shows the first move after 3 bumps.

**11. Success, session end, early exit.** Session = 5 rounds, then the end_lines and the Play again / Back to games buttons. BACK cancels any local action, then opens the pause sheet; a second BACK returns to the host. No progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". No timers, scores or streaks.

**13. Session time.** About 20-40 s per round; 5 rounds take about 2-3 min.

**14. Assets / audio / content.** Space theme: Astro the kid astronaut ({buddy}), the rocket, three planets and moon bases. Emoji (Unicode 11 or earlier, no ZWJ) in white candy cards. Spoken lines pre-recorded (Rishi), voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww027` (30 rounds, rounds per level [10, 10, 10]).

**15. Accessibility.** Meaning is carried by pictures, never by colour only or by reading. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion honoured, all audio optional.

**16. Offline / failure.** Fully bundled; no network. If content fails to validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset. Stored locally: current level per game only.

**18. Tests.** `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules; every maze is solved by BFS). Each round has one defensible answer; choices distinct; answer positions vary. Plus the host contract tests and a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Framework-level support only (NCF-FS, NCERT 2022 foundational goals). Limitation: framework, not effect evidence. We claim only practice of the skill inside the activity.
