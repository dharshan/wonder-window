# WW-019 · Symmetry Butterfly (our id `ww019`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: G. Spatial Awareness & Visual Intelligence / Symmetry · Variant: `mirror`

**1. Identity.** Original title "Symmetry Butterfly", catalogue id WW-019. Source record unchanged in master.json.

**2. Age band.** Record 5-7 / 5-8; fits him with small grids (2x1 at L1).

**3. Objective (observable).** He completes the right wing so that it mirrors the left wing cell by cell.

**4. What he practises.** Reflection symmetry: the cell next to the middle copies the cell next to the middle; reversing order across a line. (Source objective: "Complete a symmetrical pattern".)

**5. Originality and dedup.** No existing game. The new 'mirror' variant is needed (pick cannot mirror emoji). Separate. Decision: **own game**.

**6. Core loop.** Butterfly body in the centre; the left wing is a rows x cols grid of shapes; the right wing is empty. He paints each right cell from a palette; Done checks it; mismatches pulse.
Example rounds:
- L1 `ww019-1-01`: "Make both wings match!", left wing [['🔶'], ['🌸']], palette 🔵 🔶 🌸. Spoken: "Look at this wing. Make the other wing the same, like a mirror!"
- L2 `ww019-2-01`: "Make both wings match!", left wing [['🔶', '🌸'], ['⭐', '🔶'], ['🔶', '⭐']], palette ⭐ 🔵 🔶 🌸. Spoken: "Look at this wing. Make the other wing the same, like a mirror!"
- L3 `ww019-3-01`: "Make both wings match!", left wing [['❤️', '❤️', '🔶'], ['❤️', '🍃', '❤️'], ['🔶', '🍃', '🔶']], palette ❤️ ⭐ 🔶 🍃. Spoken: "Look at this wing. Make the other wing the same, like a mirror!"

**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first session. Narration only on 🔊: "A butterfly's two wings match, like a mirror. Help me paint the other wing!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** Right-wing cells form a D-pad grid. OK on a cell opens the palette strip below (LEFT/RIGHT, OK paints, BACK closes the palette without painting). DOWN from the last row reaches ✅ Done. UP from the top row reaches 🔊. BACK (no palette open) opens the pause sheet. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 2x1 cells and 2 shapes, L2 3x2 and 3 shapes, L3 3x3 and 4 shapes. Palette = used shapes + 1 extra. Levels: L1 Small wings 🐛, L2 Bigger wings 🦋, L3 Big patterns 🌈.

**10. Hint / retry / recovery.** After the first Done with mismatches: the mismatched cells pulse and the matching left cell glows. After the second: the first mismatched cell's correct shape shows faintly. 🔊 always replays the line. After the second miss the answer is shown and he presses it ("You kept going!"). Nothing is lost.

**11. Success, session end, early exit.** 3 butterflies per set (rounds_per_session 3) to stay at or under 4 min. Each set is 3 rounds. BACK cancels any local action first (palette, peek), then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Butterfly gently animates or glows when complete. Soft highlight of mismatches."). Correct: one of 6 `cheers`, the scene fills (🦋), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 40-70 s per butterfly; about 2.5-3.5 min. Target 1.5-4 min (record estimate 2-4 min).

**14. Assets / audio / content.** Butterfly body and wing outline, shape palette (❤️ ⭐ 🔵 🔶 🌸 🍃, each a different shape), paint pop. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww019`.

**15. Accessibility.** Palette shapes differ by form, not only colour. Grid cells at 120 px or larger. No timer. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, complexity (max grid), reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). right = row-wise reverse of left; the palette contains all used shapes; the palette dialog's BACK never exits the game. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.
