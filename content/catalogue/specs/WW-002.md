# WW-002 · Shape Echo (our id `ww002`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: B. Memory & Concentration / Sequence Recall · Variant: `echo`

**1. Identity.** Original title "Shape Echo", catalogue id WW-002. Source record unchanged in master.json.

**2. Age band.** Record says 3-4 primary / 3-6. Fits him at L2-L4 (3-4 shapes); L1 is a warm-up.

**3. Objective (observable).** After watching 2-4 shapes light up one at a time, he presses the same shapes in the same order.

**4. What he practises.** Holding a short visual sequence in mind and reproducing it; looking carefully; waiting before acting. (Source objective: "Remember and reproduce a short visual sequence of shapes".)

**5. Originality and dedup.** Nearest: none of our 7 games trains sequence recall. Catalogue neighbours in category B (e.g. Memory Tray WW-015) detect change in a static set rather than reproduce an order, so the action differs. Decision: **own game**.

**6. Core loop.** Watch: tiles light one by one (show_ms each, 300 ms gap, a soft marimba note per tile). Then 'Your turn' and focus moves to the first tile. Press tiles in order; each correct press glows and plays its note. A miss replays the sequence slowly, and the attempt restarts with no penalty.
Example rounds:
- L1 `ww002-1-01`: "Watch, then press them in order!", pool 🔴 ⭐ 🔺 ⬛, sequence [3, 0]. Spoken: "Watch the shapes light up. There are two. Then press them in the same order!"
- L2 `ww002-2-01`: "Watch, then press them in order!", pool 🔴 ⭐ 🔺 ⬛, sequence [1, 3, 2]. Spoken: "Watch the shapes light up. There are three. Then press them in the same order!"
- L3 `ww002-3-01`: "Watch, then press them in order!", pool 🔴 ⭐ 🔺 ⬛ 💜, sequence [2, 3, 1, 0]. Spoken: "Watch the shapes light up. There are four. Then press them in the same order!"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first session. Narration only on 🔊: "My shapes light up like a song. Watch carefully, then press them in the same order!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** Watch phase: input ignored except BACK (pause) and UP to 🔊. Input phase: LEFT/RIGHT over the pool row (wraps), OK = press, UP = 🔊 / watch again. BACK = pause sheet (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 2 shapes (pool 3), L2 3 (pool 4), L3 4 (pool 5), L4 4 with colour twins (pool 6). In-set rule: 3 first-try in a row moves up one level, at most once per set. 2 misses in a row moves down silently. Levels: L1 Two shapes 2️⃣, L2 Three shapes 3️⃣, L3 Four shapes 4️⃣, L4 Colour twins 🌈.

**10. Hint / retry / recovery.** After 1 miss: replay at 1.5x slower with the voice naming the shapes. After 2 misses: replay and pulse each tile as he should press it (guided). The round always ends kindly. 🔊 always replays the line. After the second miss the answer is shown and he presses it ("You kept going!"). Nothing is lost.

**11. Success, session end, early exit.** Session = 5 rounds, then the end_lines and the Play again / Back to games buttons. Early exit any time via BACK. Each set is 5 rounds. BACK cancels any local action first (palette, peek), then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Gentle highlight of correct sequence on success. On error, soft reset of the input sequence with option to watch again."). Correct: one of 6 `cheers`, the scene fills (🎶), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 20-35 s per round; 5 rounds take about 2-3 min. Target 1.5-4 min (record estimate 1-3 min).

**14. Assets / audio / content.** 6 shape emoji tiles in white candy cards, a glow ring, 6 pentatonic notes (one per tile, C D E G A C), and the watch/your-turn cue. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww002`.

**15. Accessibility.** Tiles differ by shape, never colour only (L4 colour twins also differ in shape pairs). Parent 'slower playback' x1.5. Reduced motion: glow only, no bounce. No-audio mode: the light-up is fully visual. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, max sequence length (2-4), slower playback, reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Sequence playback timing is deterministic; a miss restarts input without losing the level; focus is never on a hidden tile; budget expiry during the watch phase stops cleanly. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Gathercole, S. E. & Alloway, T. P. (2008), Working Memory and Learning (SAGE), background on short-term sequence recall. Limitation: meta-analyses (Melby-Lervåg & Hulme, 2013, Developmental Psychology) find working-memory training does not transfer broadly, so we claim only practice of this task. We claim only practice of the skill inside the activity.
