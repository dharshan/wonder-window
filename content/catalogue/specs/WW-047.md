# WW-047 · Echo Clap
Status: **merged_into ww002** · Category: B. Memory & Concentration / Auditory Memory

**Objective (source).** Listen to a short rhythm or sound pattern and repeat it by selecting icons

**Decision.** merged_into WW-002 (Shape Echo, `ww002`).

**Reason.** Same action (repeat a short sequence by pressing icons in order). The `echo` variant has no sound-only mode, so the 'auditory' flavour cannot be a separate game; it is covered by the soft marimba note per tile in Shape Echo. A sound-only mode would need variant 'echo_audio'.
