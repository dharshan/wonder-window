**1. Identity.** Original title "Best Tool", catalogue id WW-028. Source record unchanged in master.json. Decision: **own game**.

**2. Age band.** Record says 6-7 primary / 5-7, 6-8. He is 5½: fits from L1.

**3. Objective (observable).** He chooses the most useful tool or object for a simple everyday job. (Source objective: "Choose the most appropriate tool or object for a simple everyday task".)

**4. What he practises.** Matching a tool to its purpose; practical reasoning.

**5. Originality and dedup.** No existing game asks which object helps a job. Different objective. Decision: **own game**.

**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww028-1-01`: "Which tool helps?" Spoken: "You need to cut paper. Which one helps the most? Spoon, cap, or scissors?"
- L3 `ww028-3-01`: "Which tool helps?" Spoken: "You want to hang a picture on the wall. Which one helps the most? Spanner, hammer, or scissors?"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first set. Narration only on 🔊: "Cherry has a job to do! Pick the best tool to help." Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT (and UP/DOWN on the 2x2 grid) over the choices, OK answers, UP on the speaker for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 everyday jobs, L2 tricky choices with two plausible tools, L3 think it through (magnet for paperclips). In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Everyday jobs 🧰; L2 Tricky jobs 🔍; L3 Think it through 💭.

**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Task gently completes with the chosen tool on success. Calm explanation if a less suitable tool is chosen."

**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, Cherry the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b2.json` → `ww028`.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.
