# WW-128 · Peek and Remember (our id `ww128`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: B. Memory & Concentration / Visual Memory · Variant: `pick`

**1. Identity.** Original title "Focus Land", catalogue id WW-128. Source record unchanged in master.json.

**2. Age band.** Record 5-7 (WW-130 5-6, WW-137 5-6); fits him. L1 is easy, L3 (look-alikes after a 2 s peek) is a stretch.

**3. Objective (observable).** He looks at one picture for 2-4 seconds, it hides behind a ❓, and he picks what it was from 3-4 choices.

**4. What he practises.** Holding a single picture in mind for a few seconds and recognising it among distractors; looking carefully before answering; (L3) noticing small differences between look-alikes. (Source objective: "Remember visual information after a short delay".)

**5. Originality and dedup.** Closest call in the batch: Memory Tray (ww015) also uses the `peek_board` mechanic, but there the whole tray stays on screen and he finds the one thing that changed (missing or new), so he compares two views. Here nothing stays: the picture is hidden completely (L1, L3) or one thing is hidden inside a container (L2), and he recalls it with nothing to compare. Memory Grid (ww096) matches twins by position and Shape Echo (ww002) repeats an order. Merged here: WW-130 (same delayed-recall action) and WW-137 (same objective), cluster WW-DUP-001. WW-138 (change detection) goes to Memory Tray. Decision: **own game**; reviewer to confirm it is different enough from ww015.

**6. Core loop.** The picture appears on the board for `peek_ms` (soft chime), then the board shows ❓ and the choices become active. He picks what it was. L2 shows a container (basket, present, bag, house...) with one thing inside, then the inside is hidden. A wrong pick fades the choice and shows the picture again for a moment.
Example rounds:
- L1 `ww128-1-01`: "What was hiding?", shown 🍌 for 3 s, then board ❓, choices 🎈 🍌 🌵, answer 🍌. Spoken: "Look at the picture carefully. It will hide soon. Then find what it was!"
- L2 `ww128-2-01`: "What was inside?", shown 🧺 🍎 for 2.5 s, then board 🧺 ❓, choices 🍊 🍎 🍇 🍌, answer 🍎. Spoken: "Look in the basket. Something is inside. It will hide soon. What was in the basket?"
- L3 `ww128-3-01`: "What was it? Look closely!", shown 🍅 for 2 s, then board ❓, choices 🍎 🍒 🍅 🍏, answer 🍅. Spoken: "Look closely. It will hide very soon. Some pictures look almost the same. What was it?"

**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first session. Narration only on 🔊: "the buddy (Pip) will show you something, then hide it. Look carefully, then find what it was!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the choices, OK confirms, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused. During a peek the input is ignored except BACK and UP.

**9. Difficulty.** L1 one picture, 3 choices from different groups (fruit, animal, vehicle, toy, nature), 3 s peek. L2 a container with one thing inside, 4 choices from the same group, 2.5 s. L3 one picture, 4 look-alike choices (apple, green apple, tomato, cherries), 2 s. Levels: L1 Look and hide 🙈; L2 What's inside? 🎁; L3 Quick look-alikes 👀.

**10. Hint / retry / recovery.** After 1 miss the choice fades and the `hint` is shown (voice only on 🔊); for peek rounds the picture is shown again for a moment. After 2 misses the answer is shown and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** Session = 5 rounds, then the end_lines and the Play again / Back to games buttons. Early exit any time via BACK: it cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Gentle, positive visual feedback on success. Neutral and constructive response to errors with opportunity to try again. No pressure, timers, or negative messaging."). Correct: one of 6 `cheers`, the scene fills (🙈), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 20-35 s per round; 5 rounds take about 2-3 min. Target 1.5-4 min (record estimate 1.5-4 min).

**14. Assets / audio / content.** Large emoji choice cards, ❓ cover with a soft peek-a-boo animation, a chime when the picture hides. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww128` (30 rounds, 3 levels).

**15. Accessibility.** Meaning is carried by the pictures, not by colour alone; labels are screen text for the parent only. `peek_ms` is 2-3 s and the parent can raise it (slower playback x1.5). A sound plays when the picture hides so it is not vision-only. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, starting level, reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Each round has one defensible answer (plus `also_ok` where listed); choices distinct; labels match choices; `fade` is never a right answer. `peek_board` has the same length as `board`, exactly one position differs (the ❓), and the answer equals the hidden picture; `peek_ms` 1000-8000; look-alike groups are four distinct emoji with distinct labels. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Gathercole, S. E. & Alloway, T. P. (2008), Working Memory and Learning (SAGE), background on short-term visual memory. Limitation: meta-analyses (Melby-Lervåg & Hulme, 2013, Developmental Psychology) find memory-training does not transfer broadly, so we claim only practice of this task. We claim only practice of the skill inside the activity.
