# WW-129 · Hide Quest (our id `ww129`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: B. Memory & Concentration / Paired Associate Memory · Variant: `pick`

**1. Identity.** Original title "Hide Quest", catalogue id WW-129. Source record unchanged in master.json.

**2. Age band.** Record 3-5 (WW-136 5-7); fits him at L1-L2, L3 (short peek, other pair's items as choices) is a stretch.

**3. Objective (observable).** He sees two pairs of pictures (an animal and a thing, joined by an arrow), one picture hides, and he picks which one went with the visible partner.

**4. What he practises.** Binding two things together in memory (paired-associate memory): remembering who went with what, not only what was there. (Source objective: "Remember which items were paired together".)

**5. Originality and dedup.** Nearest: Memory Grid (ww096) finds identical twins by position, Peek and Remember (ww128) recalls one picture, Memory Tray (ww015) finds what changed. Here the pairs are different things made up on the spot (dog with hat), so he must remember the link; natural pairs (bee and flower) are avoided on purpose because common sense would answer them without memory. Merged here: WW-136 (same objective; its 'grid_path' label is only intake's rough family). Decision: **own game**; reviewer to confirm. Three pairs would need a board of 9 pictures (the board holds at most 8), so a 3-pair level is not built.

**6. Core loop.** Two pairs appear for `peek_ms` (animal ➡️ thing). Then one of the four pictures is replaced by ❓ and the voice (🔊) asks which one goes with the visible partner. He picks from 3-4 choices.
Example rounds:
- L1 `ww129-1-01`: "Who goes with who?", shown 🐮 ➡️ 🍎 🐢 ➡️ 🎩 for 4 s, then board 🐮 ➡️ 🍎 ❓ ➡️ 🎩, choices 🐒 🐟 🐢, answer 🐢. Spoken: "Look at the pairs. Remember who goes with who. Soon one will hide. Which one goes with the hat?"
- L2 `ww129-2-01`: "Who goes with who?", shown 🐶 ➡️ 🎁 🐮 ➡️ 🔑 for 3 s, then board 🐶 ➡️ 🎁 🐮 ➡️ ❓, choices 🎁 🥁 🔑, answer 🔑. Spoken: "Look at the pairs. Remember who goes with who. Soon one will hide. Which one goes with the cow?"
- L3 `ww129-3-01`: "Who goes with who?", shown 🐒 ➡️ ⭐ 🐢 ➡️ 📚 for 2.5 s, then board ❓ ➡️ ⭐ 🐢 ➡️ 📚, choices 🐢 🐶 🐒 🐸, answer 🐒. Spoken: "Look at the pairs. Remember who goes with who. Soon one will hide. Which one goes with the star?"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first session. Narration only on 🔊: "My friends come in pairs. Look carefully. When one hides, tell me who it was with!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the choices, OK confirms, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused. During a peek the input is ignored except BACK and UP.

**9. Difficulty.** L1 2 pairs, 4 s peek, 3 choices (the other two are new pictures). L2 3 s peek, 3 choices (one of them was on the board, in the other pair). L3 2.5 s peek, 4 choices (one from the other pair, two new). The hidden picture is the animal or the thing in turn. Levels: L1 Two pairs 2️⃣; L2 Look again 👀; L3 Quick pairs ⚡.

**10. Hint / retry / recovery.** After 1 miss the choice fades and the `hint` is shown (voice only on 🔊); for peek rounds the picture is shown again for a moment. After 2 misses the answer is shown and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** Session = 5 rounds, then the end_lines and the Play again / Back to games buttons. Early exit any time via BACK: it cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Gentle, positive visual feedback on success. Neutral and constructive response to errors with opportunity to try again. No pressure, timers, or negative messaging."). Correct: one of 6 `cheers`, the scene fills (🔗), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 20-35 s per round; 5 rounds take about 2-3 min. Target 1.5-4 min (record estimate 1.5-4 min).

**14. Assets / audio / content.** Animal and thing emoji, an arrow, the same ❓ cover as ww128. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww129` (30 rounds, 3 levels).

**15. Accessibility.** Meaning is carried by the pictures, not by colour alone; labels are screen text for the parent only. Pairs are arbitrary and silly on purpose (the elephant has a hat), which also makes them easy to say aloud. Parent can raise `peek_ms` (slower playback x1.5). Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, starting level, reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Each round has one defensible answer (plus `also_ok` where listed); choices distinct; labels match choices; `fade` is never a right answer. On the board the hidden position is never an arrow; choices are all animals or all things (never mixed); distractors never repeat the visible partner; answer equals the hidden picture. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Gathercole, S. E. & Alloway, T. P. (2008), Working Memory and Learning (SAGE), background on short-term memory and binding. Limitation: meta-analyses (Melby-Lervåg & Hulme, 2013, Developmental Psychology) find memory-training does not transfer broadly, so we claim only practice of this task. We claim only practice of the skill inside the activity.
