# WW-098 · Count On (mode `number-count-on` in core game `number`)
Status: **merged_into number** · Category: C. Mathematics & Numerical Thinking / Counting

**Objective (source).** Start from a given number and count on a small amount

**Decision.** merged_into `number` (Number Explorer, core game), as the new mode **Count On** (`number-count-on`, 30 rounds, 3 levels, 3 rounds per session).

**Reason.** Same objective family (add a few more and find the total) and same pick action as Number Explorer L4 ('How many altogether?') and the mode number-add-animals. What is new is the strategy: the first group is shown as a numeral, so he starts from that number and counts on instead of counting all from one. That is content, not a new game.

**How it plays.** Board: the start numeral, a plus sign, and 1-3 pictures. He picks the number he lands on. Example rounds:
- L1 `ww098-1-01`: "Count on! Where do you land?", board 3 ➕ 🥭, choices 5 4 3, answer 4. Spoken: "Start at three. Count on one more. What number do you land on?"
- L2 `ww098-2-01`: "Count on! Where do you land?", board 8 ➕ 🥭 🥭, choices 12 11 8 10, answer 10. Spoken: "Start at eight. Count on two more. What number do you land on?"
- L3 `ww098-3-01`: "Count on! Where do you land?", board 12 ➕ 🥭 🥭, choices 14 16 13 12, answer 14. Spoken: "Start at twelve. Count on two more. What number do you land on?"
L1 start 1-5, count on 1 (later 2); L2 start 3-8, count on 1-2; L3 start 5-12, count on 2-3. Hint: 'Say the start number in your head, then count on one at a time' (voice only on 🔊). Alias WW-098 → number recorded.

**Evidence and limits.** Counting on is a standard early-number step (NCF-FS, NCERT 2022, numeracy goals); framework, not effect evidence.
