# WW-031 · Rule Switch (our id `ww031`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: A. Cognitive & Logical Thinking / Cognitive Flexibility · Variant: `place`

**1. Identity.** Original title "Rule Switch", catalogue id WW-031. Source record unchanged in master.json. Decision: **own game**.

**2. Age band.** Record says 7-8 primary / 6-8, 7-9. He is 5½: L1 is the right level; later levels stretch.

**3. Objective (observable).** He sorts the same set of pictures by one rule, then again by a different rule. (Source objective: "Sort the same set of objects by different rules in succession".)

**4. What he practises.** Cognitive flexibility: dropping one rule and following another.

**5. Originality and dedup.** Sorting Adventure sorts by one rule at a time; here the rule changes on the same items, which is the point of the game. Same player action, different objective, so own game.

**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww031-1-01`: "Sort by colour!" Spoken: "Sort by colour. Move left and right, then press OK!"
- L3 `ww031-3-01`: "Sort by colour!" Spoken: "Sort by colour. Move left and right, then press OK!"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first set. Narration only on 🔊: "Let's sort Cherry's things. Listen to the rule. Sometimes it changes!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the nests, OK drops the current item, UP for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 four items, two rules (colour, kind). L2 six items, colour in two nests and kind in three. L3 six items, colour in three nests and kind in two. In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Two things 2️⃣; L2 More things 6️⃣; L3 Three colours 💚.

**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Clear visual rule indicator. Soft success on correct placement under current rule."

**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, Cherry the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b2.json` → `ww031`.

**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Cognitive flexibility in sorting tasks (dimensional change card sort): Zelazo, P. D. (2006), Nature Protocols. Limitation: we claim only practice inside the activity. We claim only practice of the skill inside the activity.
