# WW-044 · Attribute Switch (our id `ww044`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: A. Cognitive & Logical Thinking / Cognitive Flexibility · Variant: `place`

**1. Identity.** Original title "Attribute Switch", catalogue id WW-044. Source record unchanged in master.json.

**2. Age band.** Record 7-9; used at 5-6 with only two homes and four things, three-step levels.

**3. Objective (observable).** He sorts the same set of things into homes by colour, then straight away by what they are (and the other way round).

**4. What he practises.** Cognitive flexibility: dropping one rule and applying another to the same things. (Source objective: "Sort objects by one attribute, then immediately by a different attribute".)

**5. Originality and dedup.** Colour Nest (WW-001) and Sorting Adventure sort by one fixed attribute; here the rule changes between consecutive rounds on the same items. Different objective. Decision: own game.

**6. Core loop.** Rounds come in pairs with the same things: first 'Sort by colour', then 'Now sort by what it is' (or the reverse). Each thing goes to a home with LEFT/RIGHT and OK.
Example rounds:
- L1 `ww044-1-01`: "Sort by colour!", bins yellow / red, items 🚒 🍓 🚌 🍌. Spoken: "Put each one in the home of its own colour. Move left and right, then press OK!"
- L2 `ww044-2-01`: "Sort by colour!", bins green / yellow, items 🍋 🍌 🐢 🐤 🐸 🥦. Spoken: "Put each one in the home of its own colour. Move left and right, then press OK!"
- L3 `ww044-3-01`: "Now sort by what it is!", bins food / animals, items 🐤 🥦 🍌 🍋 🐥 🥒 🐢 🐸. Spoken: "Now switch! Put the same things in a home by what they are."

**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first session. Narration only on 🔊: "the buddy (Pip) has a puzzle! Sort the things one way. Then we switch to a new way!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the choices (or items and homes), OK confirms, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 4 things, two homes; L2 6 things; L3 8 things (two of each kind of thing). Pair order alternates. Levels: L1 Two homes, four things 🔀; L2 Two homes, more things 🧩; L3 Switch, switch, switch 🌈.

**10. Hint / retry / recovery.** After 1 miss the choice fades and the `hint` is shown (voice only on 🔊). After 2 misses the answer is shown and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** Session = 5 rounds, then the end_lines and the Play again / Back to games buttons. Early exit any time via BACK: it cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 20-40 s per round; 5 rounds take about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji (Unicode 11 or earlier) in white candy cards. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww044` (30 rounds, 3 levels).

**15. Accessibility.** Meaning is carried by the pictures, never by colour only or by reading. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Each round has one defensible answer; choices distinct; no duplicate rounds within a level. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Framework-level support only (NCF-FS, NCERT 2022, foundational numeracy, literacy and reasoning goals). Limitation: framework, not effect evidence. We claim only practice of the skill inside the activity.
