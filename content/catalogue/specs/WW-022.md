# WW-022 · Sound Sequence (our id `ww022`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: B. Memory & Concentration / Auditory Memory · Variant: `echo`

**1. Identity.** Original title "Sound Sequence", catalogue id WW-022. Source record unchanged in master.json. Decision: **own game**.

**2. Age band.** Record says 5-6 primary / 4-6, 5-7. He is 5½: fits from L1.

**3. Objective (observable).** After listening to 2-5 instrument sounds one at a time, he presses the same instruments in the same order. (Source objective: "Remember and repeat a short sequence of distinct sounds".)

**4. What he practises.** Auditory attention and short sequence recall; waiting before acting.

**5. Originality and dedup.** Nearest is Shape Echo (WW-002), which uses the same `echo` mechanic with lit shapes. The catalogue objective is auditory (sounds), the shape game is visual, and tiles here are instruments heard first. Not merged because Shape Echo is not a core game and the modality differs; flagged for reviewer: if the engine only has one tone per tile, this reduces to Shape Echo with new pictures. Decision: **own game**.

**6. Core loop.** One round at a time, 4 levels of 10 rounds (40 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww022-1-01`: "Listen, then press them in order!" Spoken: "Listen to the sounds. There are two. Then press them in the same order!"
- L4 `ww022-4-01`: "Listen, then press them in order!" Spoken: "Listen to the sounds. There are five. Then press them in the same order!"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first set. Narration only on 🔊: "Cherry's band is playing! Listen carefully, then play the same sounds in the same order!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** Watch phase: input ignored except BACK and UP for 🔊. Input phase: LEFT/RIGHT over the pool row, OK presses, UP for 🔊 or listen again. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 2 sounds (pool 3), L2 3 (pool 4), L3 4 with repeats allowed (pool 5), L4 5 (pool 6). In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Two sounds 2️⃣; L2 Three sounds 3️⃣; L3 Four sounds 4️⃣; L4 Five sounds 5️⃣.

**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Soft success animation. Option to hear sequence again on error."

**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, Cherry the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b2.json` → `ww022`.

**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Gathercole, S. E. & Alloway, T. P. (2008), Working Memory and Learning (SAGE). Limitation: Melby-Lervag & Hulme (2013) find no broad transfer from working-memory training; we claim only practice of this task. We claim only practice of the skill inside the activity.
