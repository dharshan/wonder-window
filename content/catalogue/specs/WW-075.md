# WW-075 · Rotate to Fit (our id `ww075`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: G. Spatial Awareness & Visual Intelligence / Shape Rotation · Variant: `pick`

**1. Identity.** Original title "Rotate to Fit", catalogue id WW-075. Source record unchanged in master.json. Decision: **own game (adapted to pick with turned choices)**.
**2. Age band.** Record says 6-8 primary / 6-8. He is 5½: L1 is the right level; later levels stretch.
**3. Objective (observable).** He finds which picture is the same as the one shown, only turned around (90, 180 degrees). (Source objective: "Rotate a shape so it fits into a matching hole or outline".)
**4. What he practises.** Simple mental rotation; checking shape against look-alikes.
**5. Originality and dedup.** Shadow Match (WW-009) matches an outline to its picture; here every choice is a coloured picture turned by some angle and the distractors are look-alikes. Different objective (rotation) and the record's own action (rotating a piece into a hole) needs variant `rotate`. Decision: **own game** (adapted); a real rotate-to-fit round is proposed as `{"variant":"rotate","piece":"👟","hole_deg":90,"step":90}` where LEFT/RIGHT turn the piece by `step` and OK drops it.
**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww075-1-01`: "Which one is the same, turned?" Spoken: "Look at the fish. Which one is the same picture, just turned around?"
- L3 `ww075-3-01`: "Which one is the same, turned?" Spoken: "Look at the fish. Which one is the same picture, just turned around?"
**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first set. Narration only on 🔊: "Some pictures are turned around. Find the one that is the same as this picture." Prompt text 8 words or fewer (he can't read; it is for the parent).
**8. Remote mapping.** LEFT/RIGHT (and UP/DOWN on the 2x2 grid) over the choices, OK answers, UP on the speaker for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.
**9. Difficulty.** L1 3 choices, unlike distractors; L2 3 choices with look-alikes, all turned; L3 4 choices with look-alikes, all turned. Age band 6-8 so L3 stretches him. In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Easy turns 🔄; L2 Look-alikes 👀; L3 Tricky turns 🌀.
**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.
**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.
**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Gentle positive visual confirmation on success. Neutral, non-punitive feedback on errors with option to try again. No timers or pressure."
**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.
**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, the buddy (Pip) the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b4.json` → `ww075`.
**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).
**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.
**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.
**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.
**19. Evidence and limits.** Mental rotation in early childhood: Levine et al. (2012), Developmental Psychology, show a link between spatial play and later spatial skill. Limitation: correlational; we claim only practice of this task. We claim only practice of the skill inside the activity.
