# WW-079 · Obstacle Course (mode in core `nav`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: G. Spatial Awareness & Visual Intelligence / Mazes & Pathfinding · Variant: `grid_path`

**1. Identity.** Original title "Obstacle Course", catalogue id WW-079. Source record unchanged in master.json. Decision: **merged_into nav (mode `nav-obstacle-course`)**.
**2. Age band.** Record says 5-7 primary / 5-7. He is 5½: fits from L1.
**3. Objective (observable).** He moves a friend with the arrow buttons around obstacles to a goal (L3: pick up a star on the way). (Source objective: "Guide a character through a simple obstacle course using directions".)
**4. What he practises.** Path planning; directions; going around blocks.
**5. Originality and dedup.** Little Navigator (core `nav`) has the same objective and same action (move with arrows to a goal around walls). Decision: **merged_into nav**; the mode adds 30 generated, solvable, deterministic courses (3x3, 4x4, 5x5) with cones, trees, bricks and puddles as obstacles, and a star in L3. Courses were checked by BFS: every one is solvable and the first move in the hint is on a shortest route.
**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww079-1-01`: "Help 🐶 reach 🦴!" Spoken: "Help the puppy get to the bone! Go around the bricks. Use the arrow buttons."
- L3 `ww079-3-01`: "Help 🐘 reach 🍎!" Spoken: "Help the elephant get to the apple! Pick up the star on the way. Go around the cones."
**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first set. Narration only on 🔊: "(shares the voice of core `nav`; round lines only)" Prompt text 8 words or fewer (he can't read; it is for the parent).
**8. Remote mapping.** Arrow keys (LEFT/RIGHT/UP/DOWN) move the friend one cell; walls and obstacles block; UP long-press or the speaker for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.
**9. Difficulty.** L1 3x3 (4-5 steps), L2 4x4 (6-9 steps), L3 5x5 with a star (8-12 steps). The star forces a detour of 2 or more steps. In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 Small course 🚧; L2 Bigger course 🌳; L3 Star course ⭐.
**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.
**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.
**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Gentle positive visual confirmation on success. Neutral, non-punitive feedback on errors with option to try again. No timers or pressure."
**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.
**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, Cherry the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b4.json` → merged mode `nav-obstacle-course`.
**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).
**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.
**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.
**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.
**19. Evidence and limits.** Route planning and direction words: NCERT NCF-FS (2022) spatial goals. Limitation: framework only. We claim only practice of the skill inside the activity.
