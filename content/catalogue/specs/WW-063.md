# WW-063 · Listen & Choose (our id `ww063`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: D. Language & Literacy / Listening Comprehension · Variant: `pick`

**1. Identity.** Original title "Listen & Choose", catalogue id WW-063. Source record unchanged in master.json. Decision: **own game**.
**2. Age band.** Record says 4-6 primary / 4-6. He is 5½: L1 is the right level; later levels stretch.
**3. Objective (observable).** He listens to a short spoken description and presses the matching picture. (Source objective: "Listen to a short description and choose the matching picture".)
**4. What he practises.** Listening comprehension; holding 1-3 clues in mind; matching words to pictures.
**5. Originality and dedup.** No other game plays a spoken description and asks for the picture. Word Builder and Wonder Lab ask about sounds and facts, not clues. Decision: **own game**. Note: the clue exists only as spoken audio, so this game works only after 🔊 is pressed; the prompt card shows 'Listen, then choose!' and the 👂 board; the parent can read the clue from the spoken line in the content file.
**6. Core loop.** One round at a time, 3 levels of 10 rounds (30 total), 5 rounds per set (3 for a mode). Correct answer: a cheer, the scene fills, soft sound. Wrong: neutral wobble and a hint; no penalty.
Example rounds:
- L1 `ww063-1-01`: "Listen, then choose!" Spoken: "Listen. It has a long trunk and big ears. Which picture is it?"
- L3 `ww063-3-01`: "Listen, then choose!" Spoken: "Listen. It is a fruit. It is yellow. It tastes sour. Which picture is it?"
**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first set. Narration only on 🔊: "the buddy (Pip) will say a clue about a picture. Listen, then find the picture that fits." Prompt text 8 words or fewer (he can't read; it is for the parent).
**8. Remote mapping.** LEFT/RIGHT (and UP/DOWN on the 2x2 grid) over the choices, OK answers, UP on the speaker for 🔊. BACK pauses (Keep playing / Back to games). Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.
**9. Difficulty.** L1 one clue, very different pictures; L2 two clues; L3 three clues with look-alike choices (colour, use and place together). In-set rule: 3 first-try in a row moves up one level, at most once per set; 2 misses in a row moves down silently. Levels: L1 One clue 👂; L2 Two clues 🔔; L3 Careful clues 🌟.
**10. Hint / retry / recovery.** After 1 miss: the hint line plays (on 🔊) and one wrong choice fades. After 2 misses: the answer pulses and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.
**11. Success, session end, early exit.** 5 rounds per set, then the end_lines and Play again / Back to games. BACK cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.
**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong". Record says: "Gentle positive visual confirmation on success. Neutral, non-punitive feedback on errors with option to try again. No timers or pressure."
**13. Session time.** About 20-40 s per round; a set of 5 rounds takes about 2-3 min. Target 1.5-4 min.
**14. Assets / audio / content.** Emoji pictures (Unicode 11 or older, no ZWJ) in white candy cards, the buddy (Pip) the sparrow, soft sfx. All spoken lines are pre-recorded clips (Rishi), voice only after 🔊; sounds are written as buh, mmm, sss, never letter names. Content: `catalogue/batches/b4.json` → `ww063`.
**15. Accessibility.** Meaning never depends on colour alone; large cards. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required (labels are for the parent).
**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.
**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset progress. Stored locally: current level per game only. Reset clears it without touching time settings.
**18. Tests.** Validator `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules) passes. Each round has one defensible answer; choices are distinct; spoken lines contain no isolated letters. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in every state leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.
**19. Evidence and limits.** Oral language comprehension: NCERT NCF-FS (2022) language goals. Limitation: framework only. We claim only practice of the skill inside the activity.
