# WW-016 · Size Sort (our id `ww016`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: C. Mathematics & Numerical Thinking / Measurement & Comparison · Variant: `order`

**1. Identity.** Original title "Size Sort", catalogue id WW-016. Source record unchanged in master.json.

**2. Age band.** Record 3-5 / 3-6; L1-L2 easy for him, L3 (5 close sizes) fits.

**3. Objective (observable).** He orders 3-5 copies of an object by size, smallest to biggest (some rounds biggest to smallest).

**4. What he practises.** Seriation: comparing many sizes and building an ordered line; following a direction rule. (Source objective: "Order objects by size (smallest to largest or vice versa)".)

**5. Originality and dedup.** Number Train orders by number value; this orders by visual size. Different objective. Separate. Decision: **own game**.

**6. Core loop.** The same picture at different scales (order 'scales'), shown shuffled; each OK sends the next one in size to the parade line.
Example rounds:
- L1 `ww016-1-01`: "Smallest to biggest!", order 🎈 🎈 🎈 scales [0.4, 0.7, 1.0]. Spoken: "Line up the balloons, from the smallest to the biggest!"
- L2 `ww016-2-01`: "Smallest to biggest!", order 🍪 🍪 🍪 🍪 scales [0.4, 0.6, 0.8, 1.0]. Spoken: "Line up the biscuits, from the smallest to the biggest!"
- L3 `ww016-3-01`: "Smallest to biggest!", order 🐢 🐢 🐢 🐢 🐢 scales [0.6, 0.7, 0.8, 0.9, 1.0]. Spoken: "Line up the turtles, from the smallest to the biggest!"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first session. Narration only on 🔊: "It's a size parade! Line things up from small to big." Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** As in Number Train: LEFT/RIGHT over the remaining cards, OK sends, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 3 sizes (0.4/0.7/1.0), L2 4 sizes with a few big-to-small rounds, L3 5 close sizes (0.6-1.0), alternating directions. Levels: L1 Three sizes 🐣, L2 Four sizes 🐥, L3 Five close sizes 🐔.

**10. Hint / retry / recovery.** After 2 wrong picks: a ruler line appears under the cards showing the sizes; the next correct card bounces. 🔊 always replays the line. After the second miss the answer is shown and he presses it ("You kept going!"). Nothing is lost.

**11. Success, session end, early exit.** 5 parades. Each set is 5 rounds. BACK cancels any local action first (palette, peek), then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Gentle confirmation when order is correct. Soft hint if two are swapped."). Correct: one of 6 `cheers`, the scene fills (📏), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 25-40 s per round; about 2.5-3.5 min. Target 1.5-4 min (record estimate 1.5-3 min).

**14. Assets / audio / content.** Order cards that render an emoji at a given scale (new order field 'scales'); a ruler overlay. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww016`.

**15. Accessibility.** Minimum rendered size 72 px; L3 smallest difference is 10% of 260 px (26 px), visible at 3 m. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18.
