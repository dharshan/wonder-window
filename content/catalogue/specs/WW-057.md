# WW-057 · Equal Shares (our id `ww057`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: C. Mathematics & Numerical Thinking / Simple Operations · Variant: `pick`

**1. Identity.** Original title "Equal Shares", catalogue id WW-057. Source record unchanged in master.json.

**2. Age band.** Record 6-8; first level is easier (two friends).

**3. Objective (observable).** He works out how many each friend gets when a small set is shared equally (and how many groups of a size can be made).

**4. What he practises.** Equal sharing and early division within 8. (Source objective: "Divide a small set of objects into equal groups".)

**5. Originality and dedup.** Sorting Adventure and Colour Nest sort by category; here the set is shared equally. Different. Decision: own game. Note: the record asks him to divide by action; this batch uses the pick variant (choose the share) because the place variant cannot check an equal split. A true 'drag to plates' mode would need variant 'place_equal'.

**6. Core loop.** Board shows the objects; the voice tells the number of friends or the group size; he picks the answer.
Example rounds:
- L1 `ww057-1-01`: "How many does each get?", board 🍬 🍬 🍬 🍬 🍬 🍬, choices 5 2 3, answer 3. Spoken: "Share six sweets between two friends. Everyone gets the same. How many does each one get?"
- L2 `ww057-2-01`: "How many does each get?", board 🍪 🍪 🍪 🍪 🍪 🍪 🍪 🍪, choices 2 4 5 1, answer 2. Spoken: "Share eight biscuits between four friends. Everyone gets the same. How many does each one get?"
- L3 `ww057-3-01`: "How many groups?", board 🍩 🍩 🍩 🍩 🍩 🍩 🍩 🍩, choices 1 3 4, answer 4. Spoken: "Put eight doughnuts in groups of two. How many groups can we make?"

**7. Child-facing instruction.** Visual demo by Cherry in round 1 of the first session. Narration only on 🔊: "Cherry wants to share fairly. Everyone gets the same number!" Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the choices (or items and homes), OK confirms, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 two friends; L2 three or four friends; L3 groups of two, three or four. Levels: L1 Two friends 🍰; L2 More friends 🍎; L3 Make groups 🍓.

**10. Hint / retry / recovery.** After 1 miss the choice fades and the `hint` is shown (voice only on 🔊). After 2 misses the answer is shown and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** Session = 5 rounds, then the end_lines and the Play again / Back to games buttons. Early exit any time via BACK: it cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 20-40 s per round; 5 rounds take about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji (Unicode 11 or earlier) in white candy cards. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww057` (30 rounds, 3 levels).

**15. Accessibility.** Meaning is carried by the pictures, never by colour only or by reading. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Each round has one defensible answer; choices distinct; no duplicate rounds within a level. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Framework-level support only (NCF-FS, NCERT 2022, foundational numeracy, literacy and reasoning goals). Limitation: framework, not effect evidence. We claim only practice of the skill inside the activity.
