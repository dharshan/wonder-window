# WW-004 · Letter Garden (our id `ww004`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: D. Language & Literacy / Letter Recognition · Variant: `pick`

**1. Identity.** Original title "Letter Garden", catalogue id WW-004. Source record unchanged in master.json.

**2. Age band.** Record primary 4-5 is not in its age_groups (3-4, 5-6); resolved as 4-6. Fits him now (UKG letters); L3 lower case is a stretch.

**3. Objective (observable).** Given a big target letter, he selects the identical letter among 4 (L1), the identical letter among 6 look-alikes (L2), or its lower-case partner (L3).

**4. What he practises.** Visual discrimination of letter forms; upper and lower case pairing; hearing the letter's sound on success (consonants only). (Source objective: "Match a target letter (spoken and/or shown) to its visual form".)

**5. Originality and dedup.** Word Builder L2 is picture to first letter (a sound to letter mapping); this is letter to letter (visual form). The objective differs, so it stays separate. Decision: **own game**.

**6. Core loop.** Big letter on a sign, letter flowers below. Pick the match; the flower blooms and the sound plays (buh, mmm...).
Example rounds:
- L1 `ww004-1-01`: "Find the same letter!", board B; choices X L B O; answer B. Spoken: "Look at the big letter. Find the same one in the garden!"
- L2 `ww004-2-01`: "Find the same letter!", board E; choices H F T L E B; answer E. Spoken: "Look carefully! Some letters look alike. Find the same one!"
- L3 `ww004-3-01`: "Find its small letter!", board A; choices d e a o; answer a. Spoken: "This is a big letter. Find the small letter that goes with it!"

**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first session. Narration only on 🔊: "Welcome to the letter garden! Find the letter that matches, and the flower blooms." Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** L1/L3: one row of 4, LEFT/RIGHT. L2: 2x3 grid (layout grid2x3), D-pad moves spatially, no wrap between rows. UP from the top row goes to 🔊. OK selects. BACK goes to the pause sheet. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 4 distinct choices, L2 6 look-alikes (E/F, P/R, O/Q, M/N), L3 upper to lower (a, b, d, e...). Same in-set level rule. Levels: L1 Easy letters 🌱, L2 Look-alike letters 🌼, L3 Big and small 🌻.

**10. Hint / retry / recovery.** First miss: the tile dims, the hint plays and one wrong choice fades. Second miss: the answer glows, then 'You kept going!'. 🔊 always replays the line. After the second miss the answer is shown and he presses it ("You kept going!"). Nothing is lost.

**11. Success, session end, early exit.** 5 rounds, then the garden-full scene. BACK any time. Each set is 5 rounds. BACK cancels any local action first (palette, peek), then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Matches the record ("Flower blooms or soft positive animation on correct. Neutral return on incorrect with option to hear the letter again."). Correct: one of 6 `cheers`, the scene fills (🌷), soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 15-25 s per round; 5 rounds take about 1.5-2 min. Target 1.5-4 min (record estimate 1.5-3 min).

**14. Assets / audio / content.** Andika letters (upper and lower), flower tile art, bloom animation, consonant sound clips (shared with Word Builder). All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww004`.

**15. Accessibility.** Letters at 160 px or larger and high contrast. Spoken lines never say letter names (TTS limit). Sounds are only reinforcement. Text scale is not needed. Plus: focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, upper/lower case preference (forces L1-L2 or L3), reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Choice sets contain the target exactly once; lowercase only where case='lower'; the grid focus graph is checked with D-pad; no isolated letters in audio. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** National Early Literacy Panel (2008), Developing Early Literacy: alphabet knowledge is a strong predictor of later decoding. Limitation: predictive evidence, not proof that this game improves reading. We claim only practice of the skill inside the activity.
