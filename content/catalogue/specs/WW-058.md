# WW-058 · Letter Trail (our id `ww058`)
Status: **design_spec_draft** (awaiting father/reviewer approval) · Category: D. Language & Literacy / Letter Sequencing · Variant: `order`

**1. Identity.** Original title "Letter Trail", catalogue id WW-058. Source record unchanged in master.json.

**2. Age band.** Record 5-7; fits.

**3. Objective (observable).** He puts three to five mixed-up capital letters into alphabet order.

**4. What he practises.** Letter order and the alphabet sequence. Letters are never spoken alone; the voice only says 'like the alphabet song'. (Source objective: "Put mixed-up letters into alphabetical order or complete the sequence".)

**5. Originality and dedup.** Letter Garden (WW-004) matches letters; Story Steps orders pictures; Number Train orders numbers. Here letters are ordered. Different. Decision: own game. Note: 'complete the sequence' (missing letter) is not built.

**6. Core loop.** Mixed letters below, numbered slots above; the correct next letter flies to the next slot.
Example rounds:
- L1 `ww058-1-01`: "Put the letters in order!", order A B C. Spoken: "Put the letters in order, just like the alphabet song! Which one comes first?"
- L2 `ww058-2-01`: "Put the letters in order!", order B C D E. Spoken: "Put the letters in order, just like the alphabet song! Which one comes first?"
- L3 `ww058-3-01`: "Put the letters in order!", order B G S U X. Spoken: "Put the letters in order, just like the alphabet song! Which one comes first?"

**7. Child-facing instruction.** Visual demo by the buddy (Pip) in round 1 of the first session. Narration only on 🔊: "The letter stones got mixed up! Put them in order, like the alphabet song." Prompt text 8 words or fewer (he can't read; it is for the parent).

**8. Remote mapping.** LEFT/RIGHT over the choices (or items and homes), OK confirms, UP 🔊, BACK pause. Initial focus: 🔊 (pulsing) on the first round, then the first choice. Focus never lands on an inert element; exactly one element is focused.

**9. Difficulty.** L1 three letters in a row; L2 four in a row; L3 five letters with gaps. Levels: L1 Three in a row 🔤; L2 Four in a row 📘; L3 Skipping letters 🌟.

**10. Hint / retry / recovery.** After 1 miss the choice fades and the `hint` is shown (voice only on 🔊). After 2 misses the answer is shown and he presses it ("You kept going!"). 🔊 always replays the line. Nothing is lost.

**11. Success, session end, early exit.** Session = 5 rounds, then the end_lines and the Play again / Back to games buttons. Early exit any time via BACK: it cancels any local action first, then opens the pause sheet; a second BACK returns to the host. No confirmation is needed because no progress is lost.

**12. Feedback.** Correct: one of 6 `cheers`, the scene fills, soft `correct` sound. Miss: neutral wobble plus `tryagain` taps; never red, never "wrong".

**13. Session time.** About 20-40 s per round; 5 rounds take about 2-3 min. Target 1.5-4 min.

**14. Assets / audio / content.** Emoji (Unicode 11 or earlier) in white candy cards. All spoken lines are pre-recorded clips (Rishi), with voice only after 🔊. Content: `catalogue/catalogue_games.json` → `ww058` (30 rounds, 3 levels).

**15. Accessibility.** Meaning is carried by the pictures, never by colour only or by reading. Focus ring #F59E0B 8 px plus glow, targets at least 240 px, reduced-motion flag honoured, all audio optional, no reading required.

**16. Offline / failure.** Fully bundled; no network. If content fails to load or validate, the card is hidden and an error screen returns to the host.

**17. Parent options / data.** Enable/disable, rounds per set (4 or 5), reset. Stored locally: current level per game only. Reset clears it without touching time settings.

**18. Tests.** Validator: `validate_games.py` (schema, answer keys, 8-word prompts, Unicode 11 emoji, TTS rules). Each round has one defensible answer; choices distinct; no duplicate rounds within a level. Plus host contract tests: launch blocked when disabled or out of budget; budget expiry in instructions, play, feedback and pause leads to a calm end; BACK in every state; cold start in airplane mode; a real-remote pass on the OnePlus TV.

**19. Evidence and limits.** Framework-level support only (NCF-FS, NCERT 2022, foundational numeracy, literacy and reasoning goals). Limitation: framework, not effect evidence. We claim only practice of the skill inside the activity.
