# Asset provenance and licences

Every non-code file the app ships, where it came from and its licence. Add a row when you add an asset.

| Asset | Path | Source | Licence |
| --- | --- | --- | --- |
| Fredoka (variable) | `app/src/main/assets/fonts/Fredoka.ttf` | Google Fonts, Fredoka project | SIL Open Font License 1.1 (`OFL-Fredoka.txt`) |
| Andika Bold | `app/src/main/assets/fonts/Andika-Bold.ttf` | SIL International | SIL Open Font License 1.1 (`OFL-Andika.txt`) |
| 7 sound effects (chime, boing, pop, fanfare, twinkle, bump, chirp) | `app/src/main/assets/sfx/*.wav` | Synthesized by `tools/assets/make_sfx.py` (sine tones; byte-identical output) | MIT (generated by project code) |
| Buddy poses, clouds, hills, banner, launcher icon | `app/src/main/res/drawable/*.xml`, `res/mipmap-anydpi-v26/` | Original vector drawables made for this project | CC BY 4.0 (see LICENSE-DOCS); name and mascot also covered by TRADEMARKS.md |
| Emoji in content | rendered by the TV's system emoji font | Not shipped by this app | Device font licence |
| Game, TRY and warm-up text | `app/src/main/assets/*.json` | Written for this project | CC BY 4.0 |
| Channel list | `catalog/channels_v2.json` | Channel IDs (public references) + our own row text | Row text CC BY 4.0; IDs are references, not content |

Not shipped and not committed:
- **Spoken voice clips.** `tools/make_voice.py` generates them locally with the macOS `say` command. Redistribution rights for system-generated speech are not verified, so clips are never committed or attached to releases. The app works silently without them.
- **YouTube titles and thumbnails.** Fetched locally from public RSS feeds into `catalog/catalog.json`, which is git-ignored.
