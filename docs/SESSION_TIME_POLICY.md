# Shared session/time policy

A parent-configured shared budget applies to on-screen use across pillars. The central host/session manager is the only accounting authority. TV navigation, previews and TRY instructions count. TRY activity away from TV is not charged. Games cannot earn, unlock or extend time. Features cannot create global timers or bypass parent controls. Session end should be calm and predictable. Exceptions require explicit product decision, policy update and tests.
