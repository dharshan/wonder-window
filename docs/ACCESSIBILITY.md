# Accessibility

All child flows work with UP/DOWN/LEFT/RIGHT/OK/BACK. Focus must be visible, stable and restored after navigation. Never use colour alone. Use readable TV-distance typography, contrast, plain language and uncluttered layouts. Provide alternatives for motor, hearing, vision, mobility, speech and material needs. Avoid audio-only or precision-timing dependence. Respect reduced motion. Real-TV validation is required; emulator-only review is insufficient.
