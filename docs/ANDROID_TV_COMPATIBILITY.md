# Android TV compatibility

Target remote-only Android TV. Initial planned validation target: Android 10/API 29, 1080p (starting target, not a broad compatibility claim).

For each tested device record model, Android/API, resolution, RAM class if known, app build, remote buttons, cold launch/resume/sleep-wake/back, focus paths, performance/memory/crashes and parent/session behaviour. Do not raise min SDK or claim device-family support without evidence.
