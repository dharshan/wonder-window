# Design system contribution guide

Aim for calm, welcoming, playful and TV-distance readable. Preserve the established Sky Garden direction where available: sky, hills, clouds, stars, friendly cues, large picture-led controls and clear gold focus treatment.

Use semantic tokens for colour, typography, spacing, shape, elevation, motion and focus. Components document default/focused/pressed/disabled states. PRs include rationale, age range, target-resolution screenshots, remote focus sequence, contrast, reduced-motion and device/emulator notes. Do not replace the visual system wholesale without proposal and evidence.
