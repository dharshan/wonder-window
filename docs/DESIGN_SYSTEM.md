# Design system contribution guide

Aim for calm, welcoming, playful and TV-distance readable. Preserve the established Sky Garden direction: sky, hills, clouds, stars, friendly cues, large picture-led controls and a clear two-tone gold focus treatment.

The reusable creative system is documented in [Wonder System](design/2026-wonder-system.md). It defines the shared world grammar, three realm identities, storybook cut-paper illustration language, Pip character bible, motion tokens, transition choreography, static reduced-motion equivalents and three-discipline scorecards. The [2026 UI/UX blueprint](design/2026-ui-ux-blueprint.md) remains the screen-by-screen design proposal.

Use semantic tokens for colour, typography, spacing, shape, elevation, motion and focus. Components document default/focused/pressed/disabled states. PRs include rationale, age range, target-resolution screenshots, remote focus sequence, contrast, reduced-motion and device/emulator notes. Do not replace the visual system wholesale without proposal and evidence.

**Design gate:** picture before words; one primary invitation per screen; predictable UP/DOWN/LEFT/RIGHT/OK/BACK; focus visible without animation; no colour-only states; all content meaningful with sound off; TRY leads away from the TV. Design SVGs are concepts, not production assets or runtime proof.
